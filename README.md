# Modul-2_Transaction-test

## Тестовое задание МОДУЛЬ 2 - Конкурентность

### 1. Описание 

* Проект для сдачи практической части второго модуля по обучению программирования на GOLANG.
* Состоит из 4-х частей:
    1. Основы – создание пользователей и выполнение простых транзакций
    2. Добавление транзакций и обработка нескольких пользователей
    3. Введение в конкурентность — обработка транзакций с горутинами
    4. Реализация конкурентного доступа

### 2. Требования

* Для запуска вам понадобится редактор кода [Visual Studio Code](https://code.visualstudio.com/?wt.mc_id=DX_841432)
* Для внесения изменений в код прогаммы вам понадобится язык программирования [Go](https://go.dev/doc/install)

### 2. Установка и запуск

* Для установки игры на ваш ПК требуется скачать все файлы с репозитория сайта [GitHub](https://github.com/rocot-tech/Modul-2_transaction-test-) в отдельльную папку.
* Запустите Visual Studio Code на вышем ПК. Далее в Visual Studio Code нажмите кнопку _File_, затем нажмите кнопку _Open Folder_ и выберите папку, в которую вы сохранили файлы игры. В меню _EXPLORER_ быберите файл **main.go**
* Для запуска игры в программе Visual Studio Code запустите терминал. Чтобы запустить терминал, нажмите кнопку _View_, далее нажмите кнопку _Terminal_. 
* В терминале пропишите команду `go run main.go` и нажмите клавишу **Enter**

### 3. Функция программы

* Обмен транзакциями (денежными переводами) с защитой от отрицательного баланса денежных средств и ошибочного перевода 

### 4. История изменений

* v1 - создание пользователей через структуру и реализация методов увеличения/уменьшения баланса
* v2 - создание структуры для предоставления транзакции; создание структуры для хранения информации о пользователях и транзакциях; 
   реализация метода по обработке тразакций
* v3 - создание канала для обмена транзакциями; функции для обработки транзакций; добавлены горутины для обработки транзакций параллельно
* v4- добавлен Mutex для предотвращения гонки данных и ошибочного чтение/записи данных (защита от ошибочных балансов)
